# Anurag Chaudhary — HTML & CSS Portfolio

A premium dark-blue responsive portfolio built with **HTML5 and CSS3 only**, aligned with the HTML & CSS Internship Project Guide.

## Files
- `index.html` — semantic page structure and portfolio content
- `style.css` — theme, layouts, responsive rules, and visual styling
- `images/` — optional local images (not required for this design)
- `screenshots/` — save desktop and mobile screenshots here

## Before submitting — important personalisation
1. In `index.html`, replace `YOUR_EMAIL@example.com` with the email address you want to publish.
2. Replace the generic LinkedIn and GitHub links with your exact public profile URLs.
3. Review every skills label and keep only tools/concepts you can confidently discuss.
4. Check project wording against your completed Forage simulations and remove any claim that you cannot substantiate.
5. Open the site locally and test every navigation link on desktop and mobile.

## Run locally
Open `index.html` in Chrome or Edge. No installation, build process, JavaScript, or framework is required.

## Host free with GitHub Pages (optional)
1. Create a public GitHub repository, for example `anurag-portfolio`.
2. Upload `index.html`, `style.css`, and any assets.
3. In the repository, open **Settings → Pages**.
4. Choose deployment from the `main` branch and the root folder, then save.
5. Wait for the published URL and test it in a private/incognito window.

## Required submission items from the guide
